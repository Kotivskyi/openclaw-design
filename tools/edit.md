# edit

**Source:** pi-agent-core built-in (`src/agents/pi-tools.read.ts`)
**Group:** `group:fs`
**Mutation:** Always mutating

## Description

Make precise edits to files.

## Parameters

| Param | Type | Required | Description |
|-------|------|----------|-------------|
| `file_path` | string | Yes | Path to file |
| `old_text` | string | Yes | Text to find and replace |
| `new_text` | string | Yes | Replacement text |
