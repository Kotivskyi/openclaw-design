# sessions_list

**Source:** `src/agents/tools/sessions-list-tool.ts`
**Group:** `group:sessions`
**Mutation:** Read-only

## Description

List other sessions (incl. sub-agents) with filters/last.

## Parameters

| Param | Type | Required | Description |
|-------|------|----------|-------------|
| `filter` | string | No | Filter by session key pattern |
| `last` | number | No | Return only the N most recent sessions |
