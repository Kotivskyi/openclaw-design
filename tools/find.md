# find

**Source:** pi-agent-core built-in
**Group:** `group:fs` (implied)
**Mutation:** Read-only

## Description

Find files by glob pattern.

## Parameters

| Param | Type | Required | Description |
|-------|------|----------|-------------|
| `pattern` | string | Yes | Glob pattern to match files |
| `path` | string | No | Base directory to search from |
